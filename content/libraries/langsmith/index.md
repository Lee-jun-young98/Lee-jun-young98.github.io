# LangSmith

LangSmith는 LLM 애플리케이션의 실행 과정을 추적하고, 문제를 디버깅하고, 이후 평가와 운영 관측으로 이어 가기 좋게 정리해 주는 도구다.

처음에는 tracing과 project 구성을 중심으로 익히고, 이후에는 evaluation, automation, feedback 흐름까지 확장하는 식이 안정적이다.
