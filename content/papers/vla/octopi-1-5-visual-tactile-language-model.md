# 한 줄 요약

**Octopi-1.5는 촉각 영상을 언어로 설명하는 모델에 유사 물체 검색을 붙여, 만져 본 물체의 기억을 대화와 추론에 활용하는 VTLM이다.** 물체 맞히기에서 RAG의 효과가 크지만, 미지 물체의 물성 비교와 실제 로봇 제어까지 해결했다고 보기는 어렵다.

이 글은 [arXiv v1 원문](https://arxiv.org/pdf/2507.09985v1)을 기준으로 작성했다. 아래의 수치는 저자 보고값이며, 성능을 직접 재현한 결과는 아니다. 해석과 후속 실험 제안은 별도로 구분한다.

# 왜 촉각을 언어 모델에 연결하는가?

물체의 외형은 카메라로 볼 수 있지만, 얼마나 눌리는지나 접촉면이 얼마나 거친지는 실제로 만져야 구별하기 쉽다. Octopi-1.5의 목표는 이런 촉각 관측을 사람이 질문하고 비교할 수 있는 언어 표현으로 바꾸는 것이다.

대표 시나리오는 사과·오렌지·키위라는 후보를 먼저 알려 준 뒤, 물체를 잡을 때 얻은 촉각만으로 어떤 과일인지 맞히는 게임이다. 여기서 “촉각만 사용”한다는 것은 **접촉 중 새 시각 입력을 제공하지 않는다**는 뜻이다. 후보 목록은 앞서 언어나 이미지로 주어질 수 있으므로, 아무런 후보 정보 없이 모든 사물을 알아맞히는 설정과는 구별해야 한다. [근거: §IV-A, Fig. 7]

# 핵심 기여

1. **촉각 표현과 기반 VLM을 갱신한다.** 여러 GelSight 데이터셋으로 촉각 인코더를 학습하고 Qwen2-VL을 사용한다.
2. **한 물체 안의 여러 부위를 다룬다.** 빗의 손잡이와 솔처럼 부위마다 다른 촉감을 기술하고 비교한다.
3. **검색 가능한 촉각 메모리를 추가한다.** 새 입력과 비슷한 기존 물체의 이름·촉감 설명을 찾아 추론에 활용한다. 새로운 항목을 메모리에 넣는 teaching도 시연한다.
4. **손으로 조작하는 TMI를 제시한다.** 로봇 팔 없이도 사람이 물체를 집고 모델과 상호작용할 수 있게 한다. [근거: §I, §III]

# Method: 촉각 입력은 어떻게 답변이 되는가?

> 원문 Fig. 2 발췌. 왼쪽은 시각·언어·촉각 입력과 검색 모듈, 오른쪽은 촉각 인코더의 학습 구조다. 출처: [Yu et al., 2025, PDF p. 3](https://arxiv.org/pdf/2507.09985v1#page=3).

## 1. 촉각 영상에서 변화가 큰 10개 프레임 선택

GelSight Mini는 접촉에 따른 표면 변형을 영상으로 측정하는 광학식 촉각 센서다. 이 영상은 물체의 외관을 촬영한 RGB 이미지와 의미가 다르다.

모델은 모든 촉각 프레임을 처리하는 대신, 직전 프레임과의 차이가 큰 상위 10개를 선택한다. 선택한 프레임을 CLIP ViT-L/14 기반 촉각 인코더와 projection layer에 통과시켜 VLM이 받을 토큰으로 만든다. 기반 VLM은 Qwen2-VL 7B다. [근거: §III-A]

**리뷰어 해석:** 변화가 큰 순간을 고르면 계산량을 줄이면서 접촉의 중요한 변화를 포착할 수 있다. 반면 오래 지속되는 압력이나 느린 변형도 중요한 과업에서는 이 휴리스틱이 충분한지 별도 검증이 필요하다. 논문은 프레임 선택 방식의 비교 실험을 제시하지 않는다.

## 2. 촉각 인코더를 먼저 학습한 뒤 언어 모델에 연결

첫 단계는 촉각 CLIP 모듈의 학습이다. 같은 물체·부위의 입력과 다른 물체·부위의 입력을 구별하는 contrastive loss, 사람이 매긴 경도·거칠기 점수를 예측하는 regression loss를 함께 사용한다. 양성·음성 샘플은 동일한 GelSight 패드 유형 안에서 뽑는다. 인코더는 30 epoch 학습하며, 미지 물체 6개로 구성한 검증 집합의 loss로 모델을 선택한다.

두 번째 단계에서는 촉각 CLIP 모듈을 고정하고 projection과 decoder를 학습한다. 저자는 decoder 학습에 Visual Prompt Tuning을 사용한다고 설명한다. 학습 과제는 물체·부위의 촉감 설명과 경도·거칠기 순위 매기기다. 원문에서 이를 포괄적으로 “end-to-end fine-tuning”이라 부르기도 하지만, 구체적인 절차에는 CLIP을 고정한다고 명시되어 있다. 따라서 모든 파라미터를 함께 갱신한다고 해석하면 안 된다. [근거: §III-A, Fig. 3]

| 학습 데이터       | 물체 수 | 촉각 영상 수 |
| ----------------- | ------: | -----------: |
| PhysiCLeAR-Plain  |     100 |        2,689 |
| PhysiCLeAR-Dotted |      68 |        1,939 |
| Hardness          |     210 |        1,860 |
| ObjectFolder-Real |     100 |        3,550 |
| 영상 수 합계      |       — |       10,038 |

출처: 원문 Table I. 영상 합계는 표의 네 값을 더한 것이다. 데이터셋 간 중복을 제거한 고유 물체 수는 제시되지 않아 물체 수를 합산하지 않았다.

경도·거칠기는 인간 주석 기준의 0–10 점수다. 경도는 누를 때의 압축 가능성, 거칠기는 손가락을 미끄러뜨릴 때 느끼는 마찰에 관한 지침으로 정의된다. 즉, 이 점수를 정밀하게 교정된 물리 단위의 재료 상수로 취급해서는 안 된다. [근거: Table II]

## 3. RAG: 촉각으로 검색하고 텍스트를 가져오기

검색 경로는 다음과 같다.

1. 선택한 촉각 프레임의 임베딩을 평균한다.
2. 기존 촉각 임베딩 데이터베이스에서 cosine similarity로 상위 5개 후보를 찾는다.
3. 검색된 샘플을 물체별로 모으고 검색 빈도로 우선순위를 만든다.
4. 유사 물체의 이름과 촉감 설명을 현재 설명에 보탠다. [근거: §III-A, Fig. 4]

여기서 중요한 구분은 **검색의 기준은 촉각 임베딩이고, 가져와 활용하는 정보는 텍스트라는 점**이다. 원문의 결론이 이를 text retrieval이라고 표현한다고 해서 일반적인 문장 검색만 수행한다고 이해하면 부정확하다. 검색한 촉각 샘플이나 임베딩 자체를 모델에 직접 넣는 방식은 향후 연구다. [근거: §III-A, §V]

Teaching은 새 물체의 촉각 샘플과 정보를 데이터베이스에 추가하는 방식이다. 따라서 이 결과는 가중치를 온라인으로 재학습했다는 증거가 아니라, **외부 메모리를 갱신해 새 물체와의 대응 관계를 이용할 수 있다는 증거**로 읽는 편이 타당하다.

# Robot / Embodied Setting

Tactile Manipulation Interface(TMI)는 UMI를 수정한 휴대형 그리퍼다. 한쪽 손가락에는 GelSight Mini, 다른 쪽에는 압저항식 TAC-02가 들어간다. TAC-02는 64 taxel과 1 kHz 샘플링을 제공하지만, 논문의 시연과 모델 학습은 데이터가 더 풍부한 GelSight를 주로 사용한다. **두 센서가 하드웨어에 탑재되었다는 사실과 두 센서의 융합 효과를 실험으로 입증했다는 주장은 다르다.** [근거: §II, §III-B]

사람이 TMI로 물체를 집고 노트북의 채팅 인터페이스를 사용한다. 모델 추론은 원격 워크스테이션·서버에서 실행하므로 네트워크 연결이 필요하다. 이 구성이 휴대하기 쉽다는 설명을 노트북 단독 추론이나 자율 로봇 조작 결과로 바꾸어 읽으면 안 된다. [근거: Fig. 6]

출처: Table III, §IV-A. N/A는 원문 표기이며 0%를 뜻하지 않는다. 기반 모델은 본문에서 Qwen2-VL 7B라고 설명하지만 Table III의 Octopi-1.5 행에는 8B라고 적혀 있다. 원문은 이 차이를 설명하지 않아 위 표에서는 해당 크기 표기를 생략했다.

평가 입력은 공 25개, 과일 26개, 미지 물체 41개 **샘플**이다. 서로 다른 물체가 각각 25·26·41종이라는 뜻이 아니다. 공은 야구공·봉제 공·테니스공, 과일은 사과·키위·오렌지, 미지 항목은 빗의 솔·빗 손잡이·극세사 천으로 구성된다.

같은 Octopi-1.5에 RAG를 추가하면 공은 **+40.00%p**, 과일은 **+42.31%p**, 미지 물체는 **+31.71%p** 좋아진다. Teaching 후 미지 물체 정확도는 73.17%에서 95.12%로 **+21.95%p** 높아진다. 차이는 보고값으로 계산했다.

반면 RAG 없는 Octopi-1.5의 미지 물체 정확도 41.46%는 Octopi-1 7B의 43.90%, 13B의 53.66%보다 낮다. 따라서 “기반 모델과 촉각 인코더의 개선만으로 미지 물체 일반화가 좋아졌다”는 결론은 표에서 지지되지 않는다.

**리뷰어 해석:** 이 결과의 가장 분명한 메시지는 촉각 임베딩 기반 메모리가 유용하다는 것이다. 이미 본 과일에서는 단순 Encoder-1.5도 100%다. 언어 모델이 제공하는 대화·설명 능력의 가치와, 단순 물체 식별 정확도에 주는 추가 이득은 따로 평가할 필요가 있다.

# Limitations / Discussion

## 1. 소수 물체의 예비 실험이다

정확도가 높더라도 같은 물체에서 여러 번 얻은 샘플은 서로 비슷할 수 있다. 이 실험은 폭넓은 물체 분포에서의 일반화나 통계적 안정성을 확정하기에 작다. 신뢰구간이나 여러 학습 seed에 걸친 분산도 보고되지 않는다.

추가로 확인할 것은 접촉 위치·힘·속도·센서 패드가 달라져도 성능이 유지되는지다. 새로운 물체 종류를 늘리는 평가와 같은 물체의 반복 접촉 평가는 별도로 보고하는 편이 좋다.

## 2. Teaching 후 성능은 평가 프로토콜의 설명이 더 필요하다

외부 메모리 갱신 자체는 유용한 적응 방식이다. 다만 몇 개의 새 샘플을 등록했는지, 등록용 접촉과 평가용 접촉을 어떻게 분리했는지 알아야 효과를 정확히 해석할 수 있다. 원문만으로 이를 충분히 확인하기 어렵다.

이는 데이터 누수가 있었다는 뜻이 아니다. **누수 여부를 판정하거나 적응 효율을 비교할 만큼 상세한 절차가 제시되어 있지 않다는 한계**다.

## 3. 물체 이름을 찾는 능력과 물성을 측정하는 능력은 다르다

유사 물체의 이름을 찾으면 언어 모델은 그 물체에 관한 상식으로 답할 수 있다. 이때 실제 접촉의 물성을 읽은 기여와 이름에 대한 사전 지식의 기여가 섞인다. 미지 물체 맞히기 73.17%와 경도 순위 43.33%의 차이는 이 구분을 검증할 필요성을 보여준다. 두 수치는 서로 다른 과제의 지표이므로 직접적인 성능 차이로 계산할 수는 없다.

후속 평가로는 물체 이름을 숨긴 검색, 설명만 제공하는 검색, 이름만 제공하는 검색을 비교해 볼 수 있다. 외형·이름은 같지만 경도가 다른 물체도 유용한 시험 대상이다. 이는 이 리뷰의 제안이며 원문에서 수행한 실험은 아니다.

## 4. 로봇 제어의 효용은 아직 검증하지 않았다

부드러운 과일을 조심해서 잡으라는 텍스트 답변은 실제로 힘을 조절하는 제어 정책과 다르다. 파손률, 미끄러짐, 작업 성공률을 측정한 폐루프 조작 평가가 필요하다. 원문은 텍스트 출력에 머무르며 행동 생성은 향후 과제라고 명시한다.

# VLA 관점에서 중요한 이유

**이 논문을 VLA의 촉각 인지 모듈 후보로 보는 것은 타당하지만, VLA 성능 개선의 실증으로 인용하는 것은 과하다.**

내가 주목하는 설계는 “촉각 표현을 만드는 모델”과 “새 경험을 저장하는 메모리”를 나누는 것이다. 새로운 물체마다 큰 모델을 다시 학습하지 않고 경험을 추가할 수 있다는 점에서 매력적이다. 다만 물체 이름과 몇 개의 형용사만으로 접촉의 모든 정보를 전달할 수 있는지는 별개 문제다.

향후 정책에 연결한다면 텍스트 설명과 함께 연속적인 촉각 상태를 유지하고, 검색 결과가 잘못되었을 때 제어가 어떻게 영향을 받는지도 평가하고 싶다. 이는 후속 설계에 대한 해석이며, Octopi-1.5가 구현한 행동 생성 경로를 뜻하지 않는다.

# 내가 이해한 핵심

이 논문의 강점은 새로운 거대 모델 구조보다 **촉각을 설명 가능한 표현으로 만들고, 검색 메모리와 휴대형 인터페이스까지 연결한 시스템 구성**에 있다. RAG가 작은 데모 평가에서 큰 효과를 내고, 새 항목 등록을 통한 적응 경로도 보여준다.

동시에 결과는 한계를 잘 드러낸다. 익숙한 물체를 검색해 맞히는 것은 상당히 잘되지만, 낯선 물체들의 물성을 일관되게 비교하는 일은 어렵다. 촉각 foundation model을 평가할 때 물체 인식, 물성 추정, 실제 제어를 구별해야 한다는 점이 이 논문에서 얻은 가장 큰 교훈이다.
