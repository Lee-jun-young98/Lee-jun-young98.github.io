# Quartz Publish Plan

## 왜 Quartz인가

Quartz는 Obsidian vault의 Markdown 파일을 거의 그대로 정적 블로그로 만들기 좋습니다. 처음에는 블로그 엔진 커스터마이징보다 글 정리와 발행 습관을 만드는 데 집중합니다.

## 추천 발행 흐름

1. `10_projects`에서 프로젝트 원고 작성
2. 공개 가능한 내용만 `50_blog_drafts`로 복사
3. 회사/고객사/데이터 민감 정보 제거
4. Quartz `content`로 복사
5. GitHub Pages 또는 Vercel로 배포

## 첫 공개 글 후보

1. Hydra로 LLM SFT 학습 파이프라인 만들기
2. 의료 이미지 분류 프로젝트에서 배운 실험 설계
3. YOLO 기반 화재 감지 로봇 만들기
4. DINOv2와 Milvus로 이미지 검색 시스템 구성하기
