# Portfolio Vault

Notion에 흩어진 포트폴리오/기술블로그 재료를 로컬 Markdown으로 정리하기 위한 Obsidian vault입니다.

## 사용 흐름

1. Notion에서 가져온 원문은 `00_inbox`에 둡니다.
2. 프로젝트 회고는 `10_projects`로 정리합니다.
3. 논문 리뷰는 `20_papers`, 기술 정리는 `30_ai_notes`로 나눕니다.
4. 이력서/PPT에 바로 쓸 문장은 `40_portfolio`에 둡니다.
5. 공개 가능한 글만 `50_blog_drafts`에서 블로그 글로 다듬습니다.

## 공개 우선순위

1. LLM SFT 학습 파이프라인
2. 욕창 진단 보조 AI
3. 화재 감지 로봇 / Edge AI
4. 이미지 검색 시스템
5. 포트폴리오 웹사이트 제작기
