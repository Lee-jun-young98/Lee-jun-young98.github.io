# 블로그 운영 메모

이 저장소는 Notion과 로컬 Obsidian에 흩어진 공부 기록을 Quartz 기반 블로그로 정리하기 위한 공간입니다.

## 사용 흐름

1. Notion에서 원문이나 논문 리뷰 메모를 가져옵니다.
2. 공개 가능한 내용만 `content/blog` 또는 `content/papers`에 정리합니다.
3. 글은 공부 노트 톤으로 다시 씁니다.
4. 빌드 후 GitHub Pages에 배포합니다.

## 글쓰기 기준

- 성과를 포장하는 문장보다 이해 과정과 질문을 우선합니다.
- 논문 리뷰는 핵심 아이디어, 헷갈린 점, 다음에 실험할 내용을 남깁니다.
- 내부 경로, credential, 비공개 데이터, 만료되는 Notion 이미지 링크는 공개 글에 넣지 않습니다.
